# NLP Coursework

A collection of Jupyter notebooks exploring natural language processing, from statistical language models to BERT and large language models.

## Notebooks

| Notebook | Focus |
|---|---|
| [Lab 1](lab1_NOTempty-2.ipynb) | Text preprocessing, tokenization, N-gram language models, text generation, smoothing, and perplexity evaluation on TweetEval. |
| [Lab 2](ll2.ipynb) | Document retrieval on TriviaQA using Bag-of-Words, TF-IDF, and GloVe embeddings, evaluated with Recall@K. |
| [Lab 3](lab3_NOTempty-2.ipynb) | Sentiment classification of IMDb reviews using hand-crafted features, Bag-of-Words, and BERT embeddings. |
| [Lab 4](lab4_not_empty.ipynb) | Natural language inference and analysis of contextual representations across BERT layers. |
| [Lab 5](lab5_NOt_empty.ipynb) | Document summarization on XSum using Qwen2.5-0.5B-Instruct and different prompting strategies. |

## Methods

- Text cleaning, vocabulary construction, and tokenization.
- Statistical language modeling and probabilistic text generation.
- Vector-based document ranking with cosine similarity.
- Text classification using traditional features and transformer embeddings.
- Few-shot prompting and structured prompts for summarization.
- Model comparison, validation, and error analysis.

## Getting Started

Open the notebooks in Jupyter Notebook, JupyterLab or Google Colab. Each notebook contains its own setup instructions, exercises, code, and discussion.

Some experiments require downloading datasets and pretrained models. A GPU is recommended for BERT and LLM inferences.
